## Projects

**[Hoop Bids](https://github.com/Gaarbra/nba-auction-draft)** · [live app](https://girma.me/hoopbids/)
Hoop Bids is a live NBA auction draft app. A weekly pipeline ingests, cleans, and validates stats for 4,900 players into a 6-table PostgreSQL schema. A scikit-learn regression values each player under a fixed budget, and drafters see those values in real time on a React, Node.js, and Socket.IO draft board. GitHub Actions runs the Node and pytest suites and a client build on every push.

**[Aircraft Detection in Overhead Imagery](https://github.com/Gaarbra/aircraft)** (in progress)
Aircraft Detection is a PyTorch object-detection pipeline for aerial images, still in progress. It has a dataset class that rejects invalid boxes, DIOR train, validation, and test splits that block duplicate images, and unit-tested IoU matching that scores a pretrained Faster R-CNN.

**Turbofan Engine Predictive Maintenance** (in progress)
Turbofan Predictive Maintenance is also in progress. It predicts the remaining useful life of jet engines from NASA C-MAPSS sensor data, using SQLite, SQLAlchemy, and rolling-window features in pandas.
